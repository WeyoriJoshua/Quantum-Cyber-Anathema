# Publication result tables

This directory contains compact result tables used to support the manuscript and audit the reported summary statistics.

Raw benchmark datasets, fitted model binaries, preprocessing objects, and full per-sample prediction archives are intentionally not redistributed here. They can be regenerated from the official datasets by following the repository reproduction guides.

Included:
- CICIDS2017 five-seed model metrics and paired QCA-vs-Static-VQC comparison.
- CICIDS2017 QCA-v2 validation-only development metrics/ranking/paired comparisons.
- UNSW-NB15 five-seed external-test metrics, descriptive ranking, and frozen-QCA-v2 paired comparisons.

The UNSW external test was not used for hyperparameter or threshold tuning.
